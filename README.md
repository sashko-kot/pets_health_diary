Название проекта: Система дневника здоровья питомца  
Назначение: Сервис для отслеживания графика ухода, питания и показателей здоровья домашних животных.  
Целевая аудитория: Владельцы домашних животных, заводчики.  
Предметная область: Учет параметров здоровья животных, планирование рутинных задач по уходу и кормлению.  
Основные сущности: Хозяин, питомец, график уборки, план кормления.  
Основные функции: Расчет дневной нормы корма для питомца, проверка статуса/срока уборки клетки, оценка индекса массы/состояния питомца.  
План развития: Реализация ООП, подключение базы данных PostgreSQL, создание REST API и веб-интерфейса на Django, контейнеризация.

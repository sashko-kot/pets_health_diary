# Дневник здоровья питомцев

Учебный проект для учёта хозяев, питомцев и наблюдений за их здоровьем.
Веб-приложение работает с предметными данными через SQL-запросы к SQLite.
На этом этапе Django ORM для этих данных не используется. Исходные JSON
файлы сохранены и служат источником для импорта.

## Структура данных

- `owners` — хозяева: имя и электронная почта;
- `pets` — питомцы: вид, вес, рекомендуемый вес и внешний ключ `owner_id`;
- `health_records` — наблюдения: дата, активность, аппетит, симптомы, вес и
  внешний ключ `pet_id`.

Схема таблиц и ограничений находится в `sql/schema.sql`. Проверка внешних
ключей включена для каждого соединения. Запросы приложения хранятся в
`sql/queries.sql`: списки, фильтрация, соединения таблиц, подсчёты и
группировка. Параметры пользовательского ввода передаются отдельно через `?`.

`db/database.py` открывает базу `data/pets_health.sqlite`, включает
`sqlite3.Row` и предоставляет запросы представлениям Django. Скрипт
`db/import_json.py` создаёт таблицы и переносит данные из `data/*.json`;
его повторный запуск обновляет строки по их идентификаторам.

## Страницы

- `/` — главная и количество питомцев и записей;
- `/pets/` и `/pets/<id>/` — список и карточка питомца с историей здоровья;
- `/records/` и `/records/<id>/` — список и карточка записи;
- `/records/search/` — поиск записей по симптомам;
- `/records/statistics/` — число записей и средний вес по питомцам,
  статистика симптомов.

Представления получают выборки из SQLite и передают их шаблонам. JSON остаётся
доступен консольной версии и как исходный набор для переноса; веб-страницы
используют SQLite.

## Установка и запуск

Из корня проекта в PowerShell:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\venv\Scripts\python.exe manage.py migrate
.\venv\Scripts\python.exe -m db.import_json
.\venv\Scripts\python.exe manage.py runserver
```

Сервер доступен по адресу `http://127.0.0.1:8000/`. Команда импорта безопасна
для повторного запуска и синхронизирует записи из исходных JSON.

## SQL-запросы

В `sql/queries.sql` приведено более десяти запросов по предметной области.
Они охватывают выборки, `WHERE`, `JOIN`, агрегатные функции, `GROUP BY` и
`HAVING`. Запросы списков, деталей, поиска, главной страницы и статистики
выполняются Django-представлениями.

## Проверки

```powershell
.\venv\Scripts\python.exe manage.py check
.\venv\Scripts\python.exe -m pytest -v
.\venv\Scripts\python.exe -m flake8 . --extend-exclude=venv
```

## Основные файлы

```text
db/database.py        подключение к SQLite и SQL-запросам
db/import_json.py     импорт JSON в SQLite
sql/schema.sql        схема таблиц и ключей
sql/queries.sql       SQL-запросы предметной области
data/*.json           исходные данные
data/pets_health.sqlite база для веб-приложения
```

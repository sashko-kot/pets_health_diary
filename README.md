# Дневник здоровья грызунов

Учебный проект для учёта домашних грызунов и наблюдений за их здоровьем.
Веб-интерфейс реализован на Django; консольная версия ПР3 сохранена.

## Предметная область и данные

В приложении есть хозяева, питомцы и записи осмотров. Питомец связан с
хозяином через `owner_id`, запись — с питомцем через `pet_id`. Данные загружаются
из `data/owners.json`, `data/pets.json` и `data/records.json`; предметные
объекты и операции используются консольной и веб-версиями.

На текущем этапе Django ORM не используется, предметные данные хранятся в
JSON. Формы и работа с базой данных относятся к следующим практическим
работам.

## Технологии

- Python 3.13 и Django 5.2;
- Django Template Language (DTL), HTML5, CSS3 и JavaScript;
- Bootstrap 5.3 для адаптивной сетки и компонентов;
- JSON, Git, pytest и flake8.

## Структура проекта

```text
config/                 настройки Django и корневые маршруты
templates/              базовый шаблон и общая навигация
homepage/
  templates/homepage/   главная страница и 404
  static/homepage/      CSS, JavaScript и SVG-логотип
  views.py              главная страница и обработчик 404
pets/
  templates/pets/       список, карточка питомца и карточка-включение
  views.py              список и детальная страница питомца
records/
  templates/records/    список, детальная страница и статус симптомов
  views.py              список и детальная страница записи
models/                 предметные сущности хозяев, питомцев и записей
data/                   JSON-данные приложения
storage.py              загрузка и сохранение JSON
main.py                 консольная версия проекта
manage.py               команды Django
```

Приложения `homepage`, `pets` и `records` зарегистрированы в
`config/settings.py`. Каталог шаблонов проекта подключён в `TEMPLATES["DIRS"]`,
а шаблоны приложений находятся в их собственных каталогах `templates/`.

## Страницы и маршруты

| Страница | URL | View |
| --- | --- | --- |
| Главная | `/` | `homepage.views.index()` |
| Список питомцев | `/pets/` | `pets.views.pets_list()` |
| Карточка питомца | `/pets/<int:pet_id>/` | `pets.views.pet_detail()` |
| Дневник здоровья | `/records/` | `records.views.records_list()` |
| Запись дневника | `/records/<int:record_id>/` | `records.views.record_detail()` |
| Администрирование | `/admin/` | Django admin |

Списки и детали показывают сведения из JSON. Динамические страницы связывают
записи с питомцами и хозяевами; неизвестные идентификаторы и адреса
обрабатываются с HTTP 404. Именованные маршруты разделены пространствами имён
`homepage`, `pets` и `records`.

## Шаблоны и оформление

HTML формируется Django-шаблонами, а не строками во view-функциях. Общая
структура расположена в `templates/base.html`: она задаёт заголовок документа,
подключение Bootstrap и собственных стилей, навигацию, контейнер и подвал.
Дочерние шаблоны используют `{% extends %}` и блоки `{% block %}`; навигация,
карточка питомца и статус симптомов вынесены во включаемые шаблоны `{% include %}`.

Представления подготавливают контекст, после чего `render()` формирует ответ.
В шаблонах применяются циклы, условия, обработка пустых списков и фильтры
`length`, `default`, `date`. Ссылки формируются через `{% url %}` с namespaces.
Bootstrap дополнен собственным `homepage/static/homepage/css/style.css`,
изображением `logo.svg` и JavaScript-переключателем светлой/тёмной темы из
`homepage/static/homepage/js/main.js`. Статические файлы подключаются тегом
`{% static %}`.

## Установка и запуск

Из корня проекта в PowerShell:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\venv\Scripts\python.exe manage.py migrate
.\venv\Scripts\python.exe manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Для запуска консольной версии:

```powershell
.\venv\Scripts\python.exe main.py
```

## Проверки

```powershell
.\venv\Scripts\python.exe manage.py check
.\venv\Scripts\python.exe -m pytest -v
.\venv\Scripts\python.exe -m flake8 . --extend-exclude=venv
```

## Текущее состояние

Выполнен переход веб-части ПР6 на шаблоны Django: реализованы общий базовый
шаблон, наследование, включаемые компоненты, передача контекста, циклы,
условия, пространства имён URL, фильтры и статические ресурсы. Сохранены
консольная версия, JSON-хранилище и модель предметной области. Django ORM,
формы и редактирование данных через сайт ещё не реализованы.
